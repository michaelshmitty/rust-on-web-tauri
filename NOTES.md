# NOTES

# Prerequisites

- Install Rust
- Install Node.js

# Create demo

1. Install `create-tauri-app`

```sh
cargo install create-tauri-app --locked
```

2. Create a Tauri app

```sh
cargo create-tauri-app RustOnWebDemo
```

3. Get started

```sh
cd RustOnWebDemo
npm install
npm run tauri dev
```
